# BVR Technologies Pvt. Ltd. — Website

A responsive Next.js App Router website for BVR Technologies Pvt. Ltd., positioned as a software development partner for startups and small businesses.

## Run locally

1. Install Node.js (LTS).
2. Extract this project.
3. Open a terminal in the project folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open http://localhost:3000

## Before publishing

Replace or confirm:
- The placeholder email address `ADD_OFFICIAL_EMAIL_HERE` in `app/page.tsx`.
- The company logo/brand mark if BVR has an approved logo.
- Any service descriptions or technologies that do not match the team's actual capabilities.
- Add real company contact details, LinkedIn URL, registered office address and any required legal information.
- Add a real form backend/CRM integration if you want website enquiries submitted through a form.

## Build for production

```bash
npm run build
npm run start
```

## Notes

- This is a frontend website starter, not a deployed website.
- No fake client logos, testimonials, project statistics or company history have been added.
- Portfolio section can be added when BVR has approved real or clearly labelled concept projects.
